## 📖 项目简介 | Overview

**Synapse（突触工坊）** 是专为短视频创作者、自媒体矩阵运营者与 AI 视觉导演打造的**工业化内容生产桌面软件**。  
针对传统网页端 AI 聊天“线性翻找困难、上下文互相污染、改一处毁全篇”的痛点，Synapse 将内容创作重构为**「策划脑暴 ➔ 脚本撰写 ➔ 制作协助」**三大横向独立、资产单向纯净流转的工作流闭环，并内置融合行为心理学与视听语言的底层创作引擎。

**Synapse** is an industrialized content production desktop workbench built for short-form video creators, social media operators, and AI visual directors.  
To eliminate the linear scrolling fatigue and context pollution of standard AI chat interfaces, Synapse restructures content creation into a clean, three-stage horizontal pipeline—**Ideation ➔ Scriptwriting ➔ Production**—powered by a built-in behavioral copywriting rule engine and director-grade storyboarding system.

## ✨ 核心亮眼功能 | Key Highlights

### 1. 阶段一：树状并行脑暴与事实风控 | Stage 1: Tree-Structured Ideation & Risk Audit
* **🌳 树状多分支隔离深挖 (Isolated Parallel Branching)**  
  主对话输出 3–4 个切入方向后，点击卡片右下角 **`+ 独立分支展开`**，即可在右侧工作区开启彼此隔离的独立子标签页。多条创意线并行打磨，彻底告别上下文串台与反复上翻历史记录。  
  *Expand 3–4 creative directions into isolated side-by-side sub-tabs to explore multiple angles in parallel without polluting the main thread.*
* **📎 多模态本地参考投喂 (Multimodal Reference Feeding)**  
  支持单次投喂最多 3 个本地参考文件（`.txt` / `.md` / `.csv` / `.json` / `.srt` 文本、图片及 20MB 以内视频），自动拆解对标爆款的叙事结构与钩子逻辑。  
  *Feed up to 3 local reference files (text, subtitles, images, or videos up to 20MB) to deconstruct viral structures and pacing.*
* **🌐 实时联网事实核查 (Google Search Grounding)**  
  一键开启 Google Search 联网检索增强，自动核验冷知识、数据与背景事实，并在回复底部附带可点击溯源的引用链接。  
  *Toggle real-time Google Search grounding to verify facts and statistics with clickable source citations.*
* **🛡️ 「魔鬼代言人」风险与逻辑体检 (Devil's Advocate Risk & Logic Audit)**  
  内置独立审校人设，一键扫描当前策划案中的**数据存疑点**、**平台合规红线（高/中/低风险分级及安全改法）**以及**前 3 秒钩子漏洞**。  
  *Run a one-click red-team audit to catch unverified claims, platform compliance risks, and weak opening hooks before writing.*
* **🔒 洁净立项交接 (Clean Project Brief Handoff)**  
  锁定最优分支后，系统自动提炼核心论点、钩子策略与避坑提示，打包为结构化《立项简报》传递至阶段二。  
  *Lock the winning branch to compile a clean, structured Project Brief for Stage 2.*

---

### 2. 阶段二：心理学文案引擎与局部精修 | Stage 2: Behavioral Copywriting & Inline Edit
* **🧠 双赛道全流程文案规则引擎 (Dual-Track Copywriting Rule Engine)**  
  深度融合 Nir Eyal《Hooked（上瘾）》行为闭环与 Joseph Sugarman《文案训练手册》“滑梯效应（Slippery Slide）”法则，针对**赛道 A（1 分钟硬核知识/语言科普）**与**赛道 B（现实洞察/家庭情感叙事）**预设差异化参数：
  * **黄金前 3 秒（0%–10%）**：严格约束前两句总长 ≤ 25 汉字，零寒暄直击认知缺口或痛点。
  * **滑梯中段留存（10%–70%）**：每 5–8 秒植入“好奇心种子”，每 7–15 字自动标注口播断句切镜符 `/`。
  * **多变酬赏峰值（70%–85%）**：集中交付“猎物酬赏（硬核干货/物理类比）”或“自我酬赏（情绪释怀）”。
  * **自然闭环投入（85%–100%）**：杜绝生硬求赞，植入评论站队、收藏备用或首尾语境闭环。
  * **5 条红线静默质检**：自动过滤翻译腔、书面语与超时注水铺垫。  
  *Built-in copywriting handbook blending "Hooked" and Sugarman's "Slippery Slide" rules across Knowledge and Storytelling tracks, enforcing <=25-char hooks, curiosity seeds every 5–8s, `/` visual rhythm cuts, and a 5-point self-correction checklist.*
* **📑 三版本候选脚本矩阵 (3-Variant Script Candidates)**  
  基于同一份《立项简报》，一次性生成 3 套不同钩子切入流派的完整口播脚本，支持一键切换对比。  
  *Generate three distinct hook-driven script variations from a single brief for instant A/B comparison.*
* **🪄 类似 Cursor 的「局部框选微调」 (Cursor-Style Inline Edit)**  
  鼠标直接划选编辑器中的任意一句话或段落，选区上方即刻弹出悬浮指令框（内置“更口语化”、“强化悬念”、“压缩节奏”等快捷指令），**仅重写选中片段，绝不破坏其余已定稿段落**，并支持多步历史撤销。  
  *Highlight any span of text to summon a floating rewrite bar—modify only the selected lines without touching the rest of the script, backed by undo history.*
* **⚡ 一键「强化钩子」专项引擎 (1-Click Hook Enhancer)**  
  针对当前脚本开头，专项生成 3 种不同心理学流派的高留存开场方案（附带心理学拆解与全篇润色预览），一键替换正文。  
  *Generate 3 high-retention opening hook upgrades with psychological breakdowns and one-click replacement.*

### 3. 阶段三：导演级分镜与视觉资产锁 | Stage 3: Director Storyboarding & Visual Lock
* **🎬 导演级分镜卡片流 (Director-Grade Storyboard Cards)**  
  自动遵循 **9:16 竖屏 / 16:9 横屏电影构图**与**静态首帧原则**，将定稿口播脚本拆解为结构化分镜卡片（含镜号、景别、预估时长、画面描述、对应台词、运镜指令及 Midjourney 英文提示词）。  
  *Automatically break scripts into structured shot cards featuring shot size, duration, framing description, voiceover, camera movement, and Midjourney prompts.*
* **🔐 视觉资产锁 (Visual Asset Lock)**  
  顶部支持一键锁定全局画面比例（`--ar 9:16` / `--ar 16:9`）、强制电影胶片质感参数及自定义风格后缀（如 `--sref` / `--cref`），并自动清洗过时的 `--v` 版本后缀，一键复制即可生图。  
  *Lock global aspect ratios (`9:16` / `16:9`), film texture presets, and custom style suffixes across all shots while auto-stripping legacy `--v` flags.*
* **💬 单镜独立对话微调 (Single-Shot Conversational Refinement)**  
  每张分镜卡片均拥有独立的对话线程。点击单镜「对话微调」，即可针对该镜头的景别、光影或色调进行多轮修改，**不重新生成整套分镜表**。  
  *Open an isolated chat thread on any individual shot card to iterate on framing, lighting, or mood without regenerating the entire storyboard.*
* **📥 外部成品脚本直入 & 单镜自由增补 (External Script Import & Shot Insertion)**  
  支持跳过前两阶段，直接粘贴外部已完成脚本生成分镜，或在任意位置追加自定义新镜头。  
  *Import finished external scripts directly into Stage 3 or append custom shots on demand.*
* **📦 一键全案打包导出 (1-Click Full Project Bundle Export)**  
  自动将当前项目打包为包含 **策划纪要 (`.md`)**、**提词器纯净脚本 (`.txt`)** 以及 **分镜与 MJ 提示词制片表 (`.csv` / `.xlsx`)** 的完整压缩包。  
  *Export a complete `.zip` production bundle containing Markdown briefs, teleprompter scripts, and Excel/CSV storyboard sheets.*

### 4. 全局智能体、多模型容错与隐私安全 | Copilot, Multi-Model Resilience & Privacy
* **🤖 全局项目 AI 顾问抽屉 (Context-Aware AI Coach)**  
  右上角随时呼出常驻多轮对话顾问，自动感知当前项目上下文与阶段进度，辅助排查卡点。
* **🔄 503 算力拥堵自动降级容错 (Smart 503 Fallback & Multi-Provider)**  
  原生支持 Google Gemini 系列模型（`gemini-3.8-flash`、`gemini-4-hydrogen`、`gemini-4-argon` 等），当旗舰模型遇到高峰期 `503 UNAVAILABLE` 拥堵时自动执行指数退避重试并无缝降级至高速模型；同时兼容配置 DeepSeek V4、OpenAI GPT-6 与 Anthropic Claude 5.5 接口。
* **🛡️ 密钥 100% 本地隔离存储 (Local-First Privacy)**  
  所有 API Key 仅保存在用户本机的 `localStorage` 与本地配置文件中，由客户端直连模型服务商，绝不上传至任何第三方中转服务器。
* **💾 本地文件夹实时双写 + Token 预算预警 (Real-Time Local Folder Sync & Token Guardrails)**  
  支持绑定 Windows 本地目录，编辑时自动防抖写入 `.synapse.json`、`.md`、`.txt` 与 `.xlsx` 实体文件；内置实时 Token 消耗统计与黄/红双级预算预警条。
* **🎨 多语言与多色调工作室皮肤 (Multi-Language & Studio Themes)**  
  内置多语言界面切换及 4 套护眼深色工作台主题（暖炭灰 Warm Charcoal、黑曜石 Obsidian Black、午夜蓝 Midnight Navy、钛金灰 Titanium Slate）。

## 🚀 快速开始 | Quick Start

### 1. 环境准备 | Prerequisites
* **Node.js**: v20.0.0 或更高版本
* **API Key**: 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 获取免费的 Gemini API Key（或准备 DeepSeek / OpenAI / Claude 密钥）。

### 2. 安装与本地开发 | Installation & Development

```bash
# 1. 克隆仓库 | Clone the repository
git clone [https://github.com/licharlie1220-beep/Synapse-Creator.git](https://github.com/licharlie1220-beep/Synapse-Creator.git)
cd Synapse-Creator

# 2. 安装依赖 | Install dependencies
npm install

# 3. 启动本地开发服务器 | Start local dev server
npm run dev
```

### 3. 启动与打包 Windows 桌面端 | Run & Build Windows Desktop App

```bash
# 本地启动 Electron 桌面窗口预览 | Preview in Electron desktop window
npm run electron:preview

# 打包生成 Windows 安装包 (.exe) 与绿色便携版 | Build Windows NSIS installer & portable executable
npm run pack:win
```

打包完成后，可在项目根目录下的 `release/` 文件夹中找到生成的 `Synapse Setup 1.0.0.exe` 与便携版可执行文件。
