# 自媒体短视频全流程文案创作规则手册

本手册为 AI 编剧与口播脚本生成系统的底层执行规范，融合《Hooked》行为闭环、Joseph Sugarman 滑梯说服法则与 2025–2026 年抖音、TikTok、YouTube Shorts 分发规律。

## 0. 前置路由与平台基线

生成脚本前，必须先锁定所属赛道并对齐平台分发底线：
- **平台核心指标**：抖音侧重“收藏率 + 深度长评与作者回复 + 看后搜检索价值”，单一完播率仅为入门门槛；YouTube Shorts 关注“Stayed to Watch（留存观看率）”与自然重播；TikTok 侧重原生感口播与字幕完播，抵制棚拍硬广腔。
- **语速与时长基准**：中文口播按 4–5 字/秒（240–280 字/分）估算，最佳完播与兑现窗口为 22–60 秒（知识解释类建议 35–60 秒，约 150–250 汉字）。

| 维度 | 赛道 A：1 分钟硬核知识 / 语言科普类 | 赛道 B：现实洞察 / 家庭情感叙事类 |
| --- | --- | --- |
| 核心目标 | 高信息密度、类比极度直观、零废话 | 强画面感、克制不煽情、生活细节共情 |
| 语速与节奏 | 偏快紧凑（250–280 字/分），短句占 70% 以上 | 舒缓留白（180–220 字/分），转折处留 0.5–1 秒停顿 |
| 主导酬赏 | 70% 猎物酬赏（方法/认知红利）+ 30% 自我酬赏（掌控感） | 80% 自我酬赏（被理解的释怀感）+ 20% 猎物酬赏（人际洞察） |

## 1. 模块一：触发与黄金前 3 秒（0%–10% 进度）

### 底层原理
- **内部触发优于外部诱因**：首帧画面与开场白只是外部触发，真正留住用户的是激活其记忆中的焦虑、挫败、好奇痒点等“内部触发”，让脚本开场即扮演“止痛药”。
- **休格曼公理 2 & 3**：所有视觉与字幕元素只为让观众读第一句话；第一句话唯一的目的，是迫使观众进入第二句话。前 3 秒容量仅 12–15 个汉字（英文 7–8 词），必须零铺垫制造认知缺口。

### 实操句式与结构公式

先按运营目标锁定钩子方向，再从下表择一生成前两句台词（两句总长 ≤ 25 汉字，且构成强因果咬合）：
- **拉升完播/停留**：危机/恐惧、反差/反常识、好奇缺口、揭秘/内幕、微观细节切入
- **促进转化/行动**：数据/结果前置、命令/捷径、价格/成本降低、对比/替代
- **增强认同/互动**：站队/二选一、身份对号、痛点场景、负面/信任

| 钩子类型 | 核心心理机制 | 直接套用模板 / 实战例句 |
| --- | --- | --- |
| 危机/恐惧 | 点出隐性损失与风险，触发避害本能 | 模板：“你以为 X，其实 Y” / 例：“你以为在减肥，其实在掉肌肉”；“这3个设计正在吃掉你家好几平米” |
| 反差/反常识 | 推翻直觉假设，制造认知冲突 | 模板：“越 A，越可能 B” / 例：“他越对你百依顺，可能越不爱你”；“大厂未必是首选，第一份工作我更建议小公司” |
| 站队/二选一 | 亮明强立场，迫使表态与评论碰撞 | 模板：“选 A 还是 B？我选 A，因为……” / 例：“第一份工作：大厂还是小公司？我选小公司” |
| 揭秘/内幕 | 释放行业潜规则，触发猎物预期 | 模板：“在 X 行业，这 3 件事我从不做” / 例：“干了3年外卖，这3种我从不点”；“平替与大牌核心成分可能一样” |
| 痛点场景 | 具象动作 + 情绪，触发公理 5 点头说“是” | 模板：“是不是每次……一到……就……？” / 例：“放学就玩手机，吼800遍没用”；“地铁遇同事，假装看手机不敢打招呼” |
| 数据/结果前置 | 跳过铺垫先亮量化结果，倒逼追因 | 模板：“用这个方法，3 个月 X” / 例：“3个月收入翻2倍”；“9周减23斤” |
| 好奇缺口 | 只给局部事实，利用蔡格尼克效应留白 | 模板：“这 1 件事，X% 的人都……” / 例：“这1件事，90%的人都做错了” |
| 微观细节切入 | 休格曼视觉微故事，以单一感官特写建立在场感 | 模板：“凌晨两点，……只剩……的声音” / 例：“你看他袖口那个线头，其实早暗示了结局” |
| 命令/捷径 | 直接给低门槛步骤或快速路径 | 例：“用这2步，直接开始”；“先做这个版本，不用学太多” |
| 身份对号 | 开场点名目标人群，快速建立归属感 | 例：“做内容的人，这句话很重要” |
| 价格/成本降低 | 突出省钱幅度或高性价比锚点 | 例：“每年省5万，产出翻倍”；“媲美大牌，价格低60%” |
| 对比/替代 | 构建“我方交付 vs 旧方案痛点”反差 | 例：“别人承诺，我们交付” |
| 负面/信任 | 明确宣告“不做什么”，以坦诚瓦解防备 | 例：“不夸大，不套路，只给可执行方法” |

### 赛道微调参数
- **赛道 A（硬核科普）**：前两句 15–22 字；首选反差/反常识、揭秘/内幕、好奇缺口、数据/结果前置；自然嵌入长尾搜索词，首帧配报错高亮或对比图。
- **赛道 B（情感叙事）**：前两句 12–20 字；首选微观细节切入、痛点场景、站队/二选一、身份对号；首帧配无摆拍感的烟火气日常特写（如关门声、冷掉的饭菜）。

### AI 写作禁令
- 严禁“大家好，我是……”“今天我们来聊聊……”等寒暄或元叙事开场。
- 严禁第一句出现晦涩长定语、硬广宣传腔，或与正文兑现脱节的虚假标题党。

## 2. 模块二：中段留存与滑梯效应节奏控制（10%–70% 进度）

### 底层原理
- **滑梯效应与模式中断**：文案需像涂油的陡峭滑梯持续积累观看动能。每 5–8 秒植入一颗“好奇心种子”防止信息断档，每 2–4 秒制造一次视觉/听觉“模式中断”，并在 60%–70% 进度处重启好奇心回路防掉队。
- **情感先于逻辑**：遵循“用情感销售，用逻辑证明”与顺流答题原则，理性拆解前必须先完成感性共情。

### 实操句式与结构公式

1. **好奇心种子（每 5–8 秒植入一颗）**：
   - **转折推进型（5–8 秒破平滑）**：“但真正致命的还不是这个……” / “别急，事情到这儿才刚刚拐弯。”
   - **问题预判型（化解心头疑虑）**：“你肯定想问，那……不就行了吗？我一开始也这么以为，直到……”
   - **代价升级型（强化紧迫感）**：“如果只是……倒还好，可一旦……，后果就完全不一样了。”
   - **局部悬置型（60%–70% 防掉队）**：“接下来这个细节，才是整件事最反常的地方，看仔细了。”
2. **口播断句与非对称韵律**：采用“短句—长句—中句—短句—短句—长句”混排；中文每 7–15 字（约 2–3 秒）加注断句切镜符 `/`。
   - *节奏范例*：“很多人背了十年单词。/ 还是张不开嘴。/ 你以为是词汇量不够，其实是大脑根本没把声音信号和真实场景连起来。/ 听起来很抽象？/ 举个例子你就懂了。”
3. **情感先行三步转折**：`[共情状态承认（引发点头）] → [温和翻转或好奇心种子（不否定智商）] → [底层逻辑或客观事实推进]`。

### 赛道微调参数
- **赛道 A（硬核科普）**：好奇心种子每 5–8 秒一次；每 2–3 秒标注 `[切对比图/弹关键词]`；先共情“学不会/踩过坑”的无力感，再切入原理拆解。
- **赛道 B（情感叙事）**：好奇心种子每 6–10 秒一次（以动作细节微悬念推进）；标注 `[环境空镜/微表情特写]`；全程隐去大道理，仅借人物行动反差与对话潜台词传递张力。

### AI 写作禁令
- 严禁出现连续超过 10 秒无新信息增量、无具象细节或无好奇心种子推进的“注水铺垫”。
- 严禁口播“首先、其次、最后”“第一点、第二点”等书面连接词，严禁全篇句长均一，严禁把 5 分钟复杂逻辑硬塞进 15 秒。

## 3. 模块三：多变的酬赏与核心价值交付（70%–85% 进度）

### 底层原理
- **双维酬赏与防逆反**：中后段需同时交付“猎物酬赏”（实用解法/真相）与“自我酬赏”（掌控感/释怀感），严禁居高临下说教触发受众的逆反心理。
- **三大具象化技法**：用“链接（Linking）”将陌生概念桥接到日常物品；用“具体性（Specificity）”以精确数字和物理事实替代空洞形容词；用“精神投入（Mental Engagement）”留出 10% 推理空间让观众自己顿悟。
- **峰值精准落位**：核心真相或情绪高潮必须落在全片 **70%–85%** 进度区间，不在 40% 前剧透，也不拖延至结尾仓促收场。

### 实操句式与结构公式

1. **干货故事化与“链接”转换公式**：`[抽象概念] → [“说白了，它就像你每天都在做的____（生活强类比）”] → [具体实证（数字/微型故事/物理对比）] → [一句话掌控感]`。
   - *转换范例*：“老外不是语速快，他们只是懒。就像你平时喊‘吃了吗’会缩成‘吃嘛’，英语里把前后两个音粘在一起省力气，才是你听不懂的真正原因。”
2. **四段式进度与字数配比（60 秒 / 约 240 汉字基准）**：

| 进度区间 | 参考字数 | 核心剧本任务 |
| --- | --- | --- |
| 0%–60%（蓄水加压） | 140–150 字 | 黄金开场触发 + 2–3 次好奇心种子推进，逐一排除常见误区 |
| 60%–70%（二次钩子） | 25–30 字 | 抛出局部悬置钩子，对抗耐心临界点 |
| 70%–85%（酬赏峰值） | 35–45 字 | 集中交付核心规律、反转真相或可套用模型，完成前文伏笔咬合 |
| 85%–100%（余韵投入） | 20–30 字 | 停止堆砌新知识点，切入心理落点与自然互动闭环 |

### 赛道微调参数
- **赛道 A（硬核科普）**：每个专业概念必须绑定 1 个日常物理类比；核心方法控制在 1–2 个以内；规避逆反表达为“下次遇到这种情况，你可以试着套用这一个动作”。
- **赛道 B（情感叙事）**：用小道具、无声微动作或前后呼应细节承载转变（如默默留着的一盏灯）；峰值为立场错位真相或克制的善意瞬间，留白共情不做道德审判。

### AI 写作禁令
- 严禁在进度 40% 前提前剧透最终答案，严禁未经生活类比直接堆砌专业术语。
- 严禁使用“效果惊人”“极大提升”等空洞形容词，严禁在赛道 B 中炮制狗血冲突或强行鸡汤圆场。

## 4. 模块四：投入与闭环设计（85%–100% 进度）

### 底层原理
- **微投入与合规红线**：通过评论、收藏或转发激活心理一致性并加载下次触发。严格规避“你做动作、我给东西”的对价索取（严禁“点赞抽奖/关注领券/扣 1 发资料”），坚持“这东西有用、你自己决定”的无门槛理由。
- **自然重播机制**：拒绝故意在句中掐断的机械伪循环，依靠细节伏笔或语境反转赢得自然二刷。

### 实操句式与结构公式

| 结尾公式类型 | 撬动信号 | 直接套用句式模板 |
| --- | --- | --- |
| 评论区站队与经历投射 | 撬动长评碰撞 + 作者回复权重 | “如果是你，你会选……还是……？” / “你家里是不是也有过一个……的瞬间？” |
| 收藏备用与工具化留存 | 撬动收藏率与复访率 | “这套步骤现在不一定用得上，先存在收藏夹里，下次遇到……直接对照。” |
| 首尾句语境无缝闭环 | 撬动自然重播（Rewatch） | `[结尾句]`：“……所以回头看他开头说的那句话，其实早就暗示了结局。” `[回扣首句]`：“你以为……” |

### 赛道微调参数
- **赛道 A（硬核科普）**：优先“收藏备用 + 系列预告加载下个触发”，顺势植入 1 个长尾搜索词服务“看后搜”，价值说完即止。
- **赛道 B（情感叙事）**：优先“评论区经历投射/站队”，或提炼一句克制的“身份认同金句”激发转发分享，把评判空间交还观众。

### AI 写作禁令
- 严禁出现“请点赞关注”“一键三连”“评论区扣 1 领资料”“点赞过万更新下集”等诱导或虚假承诺话术。
- 严禁使用“因为真正的原因其实是——”半句强行截断的机械伪闭环，严禁强行拔高立意说教。

## 5. 模块五：输出规范与自我审查清单

### 输出格式契约
最终仅输出可直接用于提词与拍摄的纯净脚本，删去一切原则解释与括号元注释（如“此处埋设了好奇心种子”），按以下格式交付：
- **标题行**：`【赛道A/B】《备选标题》（预估时长：XX秒 / 约XX字）`
- **正文行**：每 7–15 字使用 `/` 标注口播断句，行内穿插极简 `[画面/切镜]` 提示。

### 强制质检标准（5 条红线，任意不通过则静默重写）

1. **去书面语与翻译腔**：默读检查无“不仅如此”“值得注意的是”“总而言之”“在这个快节奏的时代”等书面套话或广告腔，全部转为口语短句。
2. **黄金开头 25 字硬约束**：前两句合计 ≤ 25 个汉字（英文 ≤ 15 词），零寒暄，且首句已精准制造认知缺口或痛点触发。
3. **中段 10 秒信息增量与“刺”密度**：中段不存在连续超过 10 秒（约 40–50 汉字）无新信息增量、无具象细节或无好奇心种子推进的废话。
4. **情感先行与 70%–85% 峰值定位**：理性论证前已完成点头共情；赛道 A 专业概念均已完成物理类比且核心方法 ≤ 2 个，赛道 B 无空洞情绪词；最核心真相/反转准确落在 70%–85% 进度区间。
5. **结尾合规与零说教**：彻底清除鸡汤升华与“求点赞关注/扣 1/伪循环截断”，已自然植入“评论站队”“收藏备用”或“首尾语境闭环”中的至少一种合法投入机制。
